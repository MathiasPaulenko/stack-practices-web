# StackPractices Content Creator Skill

Skill for creating new content in the StackPractices project with full bilingual (EN/ES)
support, SEO optimization, and Astro SSG compliance.

## Usage

Invoke this skill when:

- Adding new code recipes, design patterns, documentation, or guides
- Creating new topic categories or technology sections
- Adding missing Spanish translations
- Building new listing or static pages

## Key Constraints

- **Bilingual mandatory**: Every `.md` must have a `.es.md`
- **Static-first**: No backend, no APIs, no databases
- **SEO-first**: Structured data, meta tags, canonical URLs on every page
- **Clean code**: Astro components, content collections with Zod schemas
